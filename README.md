## 🎯 Sobre o Projeto

Este projeto é um minijogo inspirado no clássico **Detona Ralph**, desenvolvido como parte do desafio prático do curso de desenvolvimento de jogos com JavaScript na plataforma da [DIO](https://dio.me). 

O objetivo do jogo é testar a agilidade: o jogador deve acertar o personagem nos blocos o mais rápido possível antes que o tempo acabe para acumular pontos!

👉 **[Jogue agora clicando aqui!](https://almile.github.io/JS-Detona-Ralph/)**

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web fundamentais, focando na manipulação do DOM e lógica de programação:

* **HTML5:** Estruturação dos elementos visuais e da interface do jogo.
* **CSS3:** Estilização, layout e responsividade.
* **JavaScript (ES6+):** Lógica do jogo, controle de tempo, pontuação, manipulação de áudio/eventos e interatividade.

---

## 🎮 Como Jogar

1. Acesse o link do jogo hospedado no [GitHub Pages](https://almile.github.io/JS-Detona-Ralph/).
2. O jogo iniciará automaticamente com uma contagem de tempo.
3. Clique sobre o personagem que aparece aleatoriamente nos blocos para somar pontos.
4. Tente alcançar a maior pontuação possível antes que o tempo se esgote!
